Layers (left sidebar)
BasemapStreet (OpenStreetMap) or Satellite (Esri World Imagery) - switch to Satellite to trace real-world features (farm boundaries, buildings, roads) as a digitizing reference when creating your own data.
FarmRestricts every layer on the map to one farm, or shows all farms.
Show labels on mapToggles permanent on-map text labels (each feature's title) on or off. When off, you only see a feature's title by clicking it.
Label style (sliders icon)Font size, weight, italic, text color, and a Boxed/Halo/Plain background style (Halo - a white text outline with no box - reads best over the Satellite basemap). Changes apply live as you adjust them.
Layer checkboxShows or hides that layer's features on the map. Doesn't affect Query, Export, or other tools — those work from all loaded data regardless of visibility.
Table iconOpens an Attribute Table tab listing every feature in that layer — no filtering needed first.
Sliders iconOpens Layer Properties — lets you change the layer's display color.
Query tab
Search by title…Filters the map and results list by feature title as you type.
Reference doctypeShows only features linked to a specific business record type (Farm, Warehouse, ...), or Any.
Geometry typeRestricts results to one geometry kind — Point, LineString, Polygon, etc.
LayerRestricts results to one specific layer.
Source moduleRestricts results to features created by a specific tool (e.g. "Map Viewer Import", "Map Viewer EPANET Plugin").
Only features in current map viewLimits results to whatever's inside the map's current pan/zoom bounds.
ClearResets every filter above.
Results listOnly populates once at least one filter above is set (kept empty otherwise so it doesn't dump hundreds of rows by default). Click a row to select and view that feature.
Draw & New Feature
Point / Line / Polygon / RectanglePick a shape, then draw it directly on the map. Finishing a shape opens the New Feature form.
TitleThe name shown on the map (as a label, if labels are on) and everywhere this feature is listed.
Reference doctype / Reference nameOptionally link this shape to an existing business record instead of leaving it standalone. Reference doctype lists every doctype registered in Spatial Entity Config (not just ones already in use), and Reference name is a live picker of that doctype's real records (e.g. Farm → "Kapkolia") — no free-typing, no typos.
Feature roleDistinguishes multiple features on the same reference record — e.g. a Farm's Boundary vs. its Gate. Leave blank for a single, unambiguous feature per record.
FarmTags this feature so the sidebar's Farm filter can find it.
NotesFree-text notes shown in the feature's detail panel.
Import
FileAccepts GeoJSON/.json, Shapefile (as a .zip of .shp/.dbf/.prj — a lone .shp loses attributes and coordinate projection), KML/KMZ, GPX, or CSV with latitude/longitude columns.
Default reference doctypeUsed only for an incoming feature that carries no reference of its own.
Default farmFallback farm tag applied to incoming features that don't already specify one.
Source module tagLabel stamped onto every imported feature, so you can find or filter them later (Query tab's Source module filter).
Export
FormatGeoJSON and KML keep every geometry type and property. GPX turns points into waypoints and lines into tracks but can't represent polygons (skipped). CSV is points-only (lat/lon + flattened properties); lines and polygons are skipped. Shapefile export isn't available — no dependable no-build-step library for writing one exists yet (import still supports it).
Layers / All / NoneChoose exactly which layers' features are included in the download, independent of what's currently checked in the sidebar.
Geoprocessing — Buffer, Measure, Centroid, Area/Length
Buffer — Distance (m)How far out to expand a ring around the currently selected feature.
Buffer — Preview / Save as featurePreview draws the ring on the map without saving; Save keeps it as a new standalone feature.
Measure distance — Start / ClearStart begins recording map clicks into a line, showing the running total distance live. Clear resets it.
Centroid — Compute / Save as featureCompute finds the geometric center point of the selected Polygon/MultiPolygon; Save keeps that point as a new feature.
Area / LengthRead-only, server-computed size of whatever feature is currently selected.
Geoprocessing — Clip, Union, Merge, Spatial Join
Clip — Feature A / Feature BCuts A down to the part that falls inside polygon B. Exact for polygon or point A; for line geometry, A is clipped to B's bounding box only (an approximation, not a true boundary clip).
Union — Feature A / Feature BMerges two overlapping polygons into one combined shape. Both inputs must be polygons.
Merge — Feature A / Feature BCombines two features of the same geometry family (both points, both lines, or both polygons) into one multi-part feature.
Spatial Join — Source featureThe feature whose spatial relationship to a layer you want to check.
Spatial Join — RelationIntersects (touches or overlaps), Source within target, or Source contains target.
Spatial Join — Target layerThe layer to test every feature in. Read-only — results are listed, not saved.
Geoprocessing — Heatmap & Weighted Overlay
Heatmap — Point layerWhich point layer's density/clustering to visualize (incidents, sightings, etc.).
Heatmap — Radius / BlurRadius controls how far each point's influence spreads in pixels; Blur softens the edges. Larger values merge nearby points into broader hotspots.
Weighted Overlay — Layer A / Layer BThe two polygon zone layers to combine (e.g. a flood buffer and a slope-risk zone). Must be two different layers with at least one polygon each.
Weighted Overlay — WeightHow much that layer counts toward the combined score (0–1). Doesn't have to sum to 1.
Weighted Overlay — Score source"Fixed value" applies one score to every zone in that layer. "Property" reads an existing numeric field already on those features instead.
Weighted Overlay — Run overlay / Save resultsRun previews the combined, colored zones on the map (this is a real geometric overlay — every overlap and leftover area is computed and correctly scored, not an approximation). Save keeps every resulting zone as a new feature carrying its combined score. For 3+ factors, save the result and overlay it again with the next layer.
Layout (print designer)
Paper / OrientationSets the printed page size (A4/A3/Letter/Legal) and rotation.
Map titleText banner printed at the top of the page. Leave blank to omit it.
GridDraws a latitude/longitude reference grid over the map, aligned to the coordinates actually shown.
NeatlineA decorative double-line border framing the map area.
Scale bar / North arrowStandard cartographic elements — the scale bar's distance is computed from the current zoom level.
Legend / positionLists currently visible layers and their colors, placed in the chosen page corner.
Refresh mapRe-captures the live map. Needed after panning, zooming, or changing layers/farm while this tab is open — the preview otherwise reuses the last capture for speed.
FormatPNG, JPG, or PDF — PDF fills the exact paper size chosen above.
Attribute Table & Layer Properties
Attribute Table searchFilters the open table by title or farm.
Attribute Table row clickSwitches back to the Map tab, selects that feature, and zooms to it.
Layer Properties — ColorUpdates every Spatial Entity Config row that uses this layer name, so the color stays consistent everywhere it's referenced — not just on this map session.
Layer Properties — Configuration listRead-only: which doctype(s), feature role(s), and geometry type(s) actually map to this layer.
EPANET plugin (water network simulation)
Network / CreatePick an existing water network or create a new one to build on. A network isn't only ever a farm's network - set its owner type (Farm, Warehouse, Location, or anything else registered in Spatial Entity Config) and owner record so its own pipe network stays separate from every other owner's. The network dropdown narrows to the map's global farm filter only for Farm-owned networks; every other owner type (or no owner) always stays visible. Each network simulates completely independently regardless of what owns it.
Network options (gear icon)Hydraulics (solver trials/accuracy, demand model), Time (duration and timesteps - 0 duration runs a single steady-state snapshot, anything above runs a real extended-period simulation), Water Quality (None/Chemical/Age/Trace analysis), Energy (pump price/efficiency), and Reactions (bulk/wall decay coefficients). Saved per network.
Add node — role / PlaceChoose Junction, Tank, or Reservoir, click Place, then click the map to position it — a form for its hydraulic properties (elevation, demand, etc.) opens immediately after.
Add link — role / DrawChoose Pipe, Pump, or Valve, click Draw, then click a start point and an end point. Moving the cursor within 5m of an existing node shows a dashed highlight ring around it — click while it's highlighted to connect exactly to that node's coordinate. Clicking with nothing highlighted leaves that end unconnected, and it gets skipped when you run the simulation.
Element listEvery node/link in the selected network, with a delete button for each.
Run simulationBuilds a hydraulic model from the network's elements and solves it with EPANET's engine.
Show results on mapOverlays the last simulation's results on the network geometry, with a color-ramp legend showing the active scale. Node color and Link color pick which result (Pressure/Head for nodes, Flow/Velocity for links) drives the ramp; pipe line-width still separately encodes flow magnitude.
